Exemplo de Cores

Esse h1 está sendo colorido através de nome das cores: blue para azul, e white para branco.

Segundo Exemplo

Esse segundo h1 está sendo colorido através do código hexadecimal de cada cor: #0000ff para azul (abraviação #00f) e #ffffff para branco.

Terceiro Exemplo

Este terceiro h1 está sendo colorido através do código RGB das cores: (0, 0, 255), para azul e (255, 255, 255) para branco.

Quarto Exemplo

Este quarto h1 está sendo colorido através do código HSL(Hue, Saturation, Luminosity ou Matiz, Saturação, Luminosidade): (240, 100%, 50%) para o azul e (0, 0%, 100%) para o branco.

Quinto Exemplo

Esse quinto h1 está sendo colorido através da ferramente de cores do Visual Studio Code, que nor permite usar todos os outros métodos acima, porém com uma representação visual, além da possibilidade de escolher a tranparência da cor, que nesse caso é 0,664.
